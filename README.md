# Signia Web — versión B2B

Landing corporativa estática pensada para publicar directamente en GitHub Pages.

## Archivos
- `index.html` — estructura y contenido.
- `styles.css` — identidad visual, responsive y componentes.
- `script.js` — menú móvil, tabs por sector y formulario de cotización.

## Publicar en GitHub Pages
1. Crea un repositorio, por ejemplo `signia-web`.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y carpeta `/root`.
6. Guarda y espera la URL de GitHub Pages.

## Nota
El formulario usa `mailto:` para funcionar sin backend. Para generación de leads real conviene conectarlo después a HubSpot, Formspree, Brevo, Zoho, un endpoint propio o la herramienta CRM de Signia.

El sitio usa la tipografía Inter/Manrope desde Google Fonts. Si necesitas una versión 100% sin dependencias externas, descarga las fuentes y reemplázalas por archivos locales.

## Dirección estratégica
La arquitectura toma como referencia patrones visibles en webs de operadores logísticos líderes: propuesta de valor directa, CTA de cotización, servicios por solución, sectores verticalizados, indicadores/capacidades, tecnología/tracking y cobertura. La diferenciación de Signia se centra en especialización, tailor-made, calidad y trazabilidad.
